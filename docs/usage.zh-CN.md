# 零件查看与文件夹恢复

## 零件孤立显示

在 3D 主视图中按住 **Ctrl + 左键点击零件**，仅显示该零件及其已开启的辅助标记。物理属性、面片统计和悬浮信息锁定到该零件，鼠标移动到空白处也不会切换或隐藏信息。

视图上方的状态条显示“孤立显示中”、零件名称和退出提示。按住 **Ctrl + 左键点击空白处**，或点击 **退出孤立显示**，恢复完整模型。已经隐藏的其他零件所在位置也算空白处。

普通点击空白不会退出孤立模式。切换模型或启动物理仿真会退出孤立模式。孤立模式不改变模型的零件层级、位置或物理参数。

## 辅助标记大小

在快捷操作栏拖动 **辅助标记** 滑块，可实时同步调整坐标轴、关节轴箭头、旋转方向指示和质心标记的长度、粗细及图标大小。

| 项目 | 设置 |
| --- | --- |
| 默认值 | 50% |
| 最小值 | 10% |
| 最大值 | 100%，对应调整前的标记尺寸 |

缩放围绕标记原点进行，质心位置和零件尺寸保持不变。碰撞体和惯性盒保留物理尺寸。新建或重新开启的标记也使用当前比例；MuJoCo 仿真中的对应标记使用同一设置。

## 打开上次文件夹和文件

通过 **加载文件夹** 选择目录后，文件面板会显示最近文件夹栏。该栏默认折叠，仅保留文件夹名称和 **打开上次文件夹** 按钮；点击左侧箭头可展开上次文件路径、选择文件夹、清除记录和启动恢复选项。

- **打开上次文件夹**：读取已保存的目录句柄，并打开该目录中最后成功查看的文件。
- **启动时恢复上次文件夹和文件**：默认开启。浏览器已授予读取权限时自动恢复；需要重新授权时显示提示，点击打开按钮后请求读取权限。
- **选择文件夹**：切换到其他目录。不同目录各自保存最后查看的文件。
- **清除记录**：删除恢复记录，不删除本机文件；其他标签页的最近文件夹栏也同步更新。启动恢复开关的选择会保留。

恢复使用文件在目录内的完整相对路径，优先级高于 `forward-01-flexiv-rizon4s-taccap.urdf` 等默认模型。同名目录通过目录句柄身份区分，同名文件通过相对路径区分。

上次文件已移动、删除或不再受支持时，会提示并打开可用的默认文件。加载失败不会覆盖最后成功查看的文件记录。文件夹不可访问时，可重新选择目录。快速切换文件或目录时，旧加载请求不会覆盖新选择。

## 记录存放位置与共用浏览器

记录保存在当前浏览器的站点数据中：

```text
IndexedDB
└── xense-robot-viewer-recent-workspaces
    └── records
```

可以在浏览器开发者工具的 **Application / 应用 → IndexedDB** 中查看。最多保留 10 个目录的访问句柄、目录名、最后文件相对路径、选择时间及启动恢复偏好；不保存模型内容或完整操作日志，不写入项目仓库，也不上传服务器。

不同站点来源（包括不同端口）和不同浏览器配置各自保存记录。共用同一个浏览器配置的人会共用记录；应用当前没有登录账号来区分这些使用者，可在切换使用者前关闭自动恢复或清除记录。隐私浏览会话结束、清理站点数据或浏览器存储不可用，都可能使记录无法保留。

清除应用记录不等于撤销浏览器的文件访问权限。需要撤销权限时，请通过浏览器的站点权限设置操作。

## 浏览器与路径说明

直接重新打开目录需要浏览器支持 File System Access API，并运行在 HTTPS 或 localhost 等安全上下文中。通常可使用支持该接口的 Chromium 浏览器。未支持时仍可选择文件和文件夹，但重新进入后需要再次选择目录；传统文件夹选择通过路径、大小和修改时间的指纹匹配记录，目录内容变化可能使旧记录无法匹配。

网页只能获取目录名和目录内部相对路径，不能读取 `~/src/xense-robot-viewer` 这样的完整本机路径。界面显示的是浏览器可见路径，并提供说明提示。

扫描目录时跳过 `.git`、`.aws`、`.codex`、`.agents`、`node_modules`、`.venv`、`venv`、`__pycache__` 和 `dist`，避免读取无关的凭据、依赖及构建目录。
